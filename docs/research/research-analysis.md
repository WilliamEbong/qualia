# Research analysis: NVivo concepts and statistical conventions

Researched 2026-10-03/04 for owner-added feature 008. This is a bounded, local mixed-methods and descriptive-data-science subset, not an assertion of NVivo feature or file-format parity. No new dependency, external model call or protected-vault access is needed.

## Primary sources and what they establish

- [NVivo vendor-hosted Windows help, `/20/win`, coding query](https://help-nv.qsrinternational.com/20/win/Content/queries/coding-query.htm): all/any code criteria, exclusion, case attributes, scoped searches, proximity, saved criteria and content retrieval. The `/15/win` equivalents were unavailable to the built-in fetch; these cited pages are the accessible `/20/win` documentation, not a claim to have verified every current NVivo edition.
- [NVivo `/20/win` matrix coding query](https://help-nv.qsrinternational.com/20/win/Content/queries/matrix-coding-query.htm): coding intersections, alternative proximity operators, scoped rows/columns, shading, charts, saved criteria/results and cell-to-evidence drill-through.
- [NVivo `/20/win` crosstab query](https://help-nv.qsrinternational.com/20/win/Content/queries/crosstab-query.htm): distinguishes coded cases/files, coding references and coding presence; count, row percentage and column percentage answer different questions. Case-attribute crosstabs require explicit case classification and attributes.
- [NVivo `/20/win` word frequency](https://help-nv.qsrinternational.com/20/win/Content/queries/word-frequency-query.htm) and [charts](https://help-nv.qsrinternational.com/20/win/Content/vizualizations/charts.htm): support scoped frequency exploration and visual presentation; Qualia's tokenizer and analysis unit below are explicit local choices.
- [Python 3.14 statistics](https://docs.python.org/3.14/library/statistics.html): the existing standard library supplies mean, median, sample standard deviation and Pearson correlation. No additional statistics runtime is required.
- [SciPy 1.18 Pearson documentation](https://docs.scipy.org/doc/scipy/reference/generated/scipy.stats.mstats.pearsonr.html): Pearson measures linear association; constant input makes the coefficient undefined. Distributional assumptions for significance testing are separate from calculating a descriptive coefficient. This is a reference, not a new dependency.
- [R development manual, `stats::cor`](https://stat.ethz.ch/R-manual/R-devel/library/stats/html/cor.html): complete-pair handling computes each pair from its available observations. Different missingness patterns can make a matrix of pairwise correlations non-positive-semidefinite. The sample covariance/variance denominator is `n - 1`.
- [SciPy Jaccard definition](https://docs.scipy.org/doc/scipy/reference/generated/scipy.spatial.distance.jaccard.html): boolean-set distance is disagreement divided by union; similarity is intersection divided by union. Counts with different intersection and union units must not be labeled ordinary Jaccard similarity.

## Precise Qualia conventions

1. Analyze only visible immutable sources/segments, case links/attributes and current assign/accept codings. Pending suggestions, rejected suggestions and superseded/removed codings do not count. Do not read protected benchmarks or invoke providers.
2. Source, case, any/all code and literal case-insensitive query filters intersect. Unknown identities and over-limit inputs are errors. Include exact selection criteria, selected segment IDs, current event IDs, codebook identities, pipeline identity and a deterministic input hash.
3. Code frequency counts distinct selected segments per code and distinct linked cases per code. Repeated actors, repeated spans and overlapping spans never inflate presence. Show segment/case denominators separately; percentages are zero or unavailable according to an explicit empty-denominator policy, never NaN.
4. Case-attribute groups use case attributes, with no implicit source-attribute inheritance. Equal duplicate values collapse; blank-only values are missing; differing nonblank values are conflicting. Keep these states distinguishable from literal user values named Missing or Conflicting.
5. One case belongs to its attribute group once. A source linked to multiple cases may contribute to multiple cases/groups; expose that caveat. Do not infer independence of linked cases or assert that marginal totals across overlapping groups are additive.
6. Same-segment co-occurrence counts a segment once per unordered code pair. Span-overlap mode requires a positive-length intersection within the segment: `max(startA, startB) < min(endA, endB)`. Offsets are Unicode code points, end-exclusive; touching boundaries do not overlap. Qualia names these modes separately rather than claiming one reproduces all NVivo proximity options.
7. Ordinary segment-set Jaccard is `|segments(A) intersect segments(B)| / |segments(A) union segments(B)|`, with null for an empty union. In overlap mode, either retain that separately labeled segment-set statistic or return null; overlap-positive count divided by segment union is a different measure. For one segment with touching A/B spans, segment Jaccard is 1 while overlap co-occurrence is 0.
8. Word counts use each **selected segment exactly once**, not entire source documents and not each coding span. Exact casefolded Unicode letter/apostrophe tokens, minimum length, explicit stopwords, result limit and tokenizer convention are included in methods/options. No implicit stemming, synonyms or language-specific stoplist. Report token count and distinct-segment frequency; capped lists retain complete match totals and contributing IDs.
9. Numeric fields must be explicitly selected by the researcher. Accept finite decimal/scientific values under a documented syntax with absolute magnitude at most `1e150`; blanks/absence are missing, malformed/nonfinite/out-of-bound/conflicting values invalid. The magnitude ceiling is a disclosed numerical safeguard. Do not silently treat numeric category labels as measurements, infer locale-specific separators, or replace missing values with zero.
10. For each field, report valid, missing and invalid counts; mean, median, minimum, maximum and sample standard deviation. Empty summaries are null; sample SD is null for fewer than two valid observations. Derived overflow also produces an explicit unavailable result/warning, never nonfinite JSON.
11. Pearson uses one point per eligible case with both fields finite. Always show complete-pair `n`, selected fields and excluded counts. Qualia deliberately returns **null for `n < 3`**, stricter than the mathematical minimum of two, to avoid presenting the trivial two-point plus/minus-one result. Constant input also returns null. Do not confuse this minimum with a sufficient inferential sample size.
12. Present correlation and co-occurrence as exploratory descriptions. No p-values, significance stars, causal statements, confidence intervals or population-generalization claims are part of this increment. A chart cannot establish sampling independence or repair biased missingness.
13. Accessible bars, heat tables and scatter plots retain exact numeric tables and evidence links. Labels expose counting unit, denominator, scope and unavailable results. Color never carries the only meaning; a case/segment drill-through preserves provenance.
14. Export deterministic JSON/CSV plus inert Python/base-R starter files; scripts run only when the researcher chooses outside Qualia. Default reports exclude transcripts, excerpt text and word rows. Attribute values are deliberately included in analysis CSV for research use and may be sensitive: no-text is not anonymous. Neutralize formula-leading strings and use stable column IDs with a dictionary and missingness states.
15. The public demo recomputes only from the already whitelisted two-transcript snapshot using the same pure function. It cannot expand to private attributes, arbitrary project data or protected material. Static controls that would change precomputed criteria explain their fixed scope.

## Focused acceptance fixtures and deliberate limits

Fixtures should cover duplicate spans/actors, rejected/removed coding, empty scope, cases with no matching coding, shared-source links, missing/conflicting attributes, Unicode apostrophes/casefolding, touching spans versus actual overlap, constant values, extreme finite numbers, unequal missingness, and `n = 0, 1, 2, 3`. Compare summaries/correlations against hand-computed values and the exported starter's output; test privacy and spreadsheet sanitization separately from numerical correctness.

Deferred: audio/video timeline coding or transcription, real-time collaboration, proprietary NVivo project formats, conceptual-map editing, proximity query languages, multilingual stemming, clustering/topic models and inferential/model-fitting workbenches. Existing human coding, memos, frozen codebooks, review, retrieval and evaluation remain their own established features. This increment adds transparent exploration and interoperable analysis exports without claiming comprehensive NVivo parity.
