# Code passages with the keyboard

Guide sections: 7
Target length: 3–4 min
Starting state: practice-study after codebook frozen

Recording note: Use the section 3 starting snapshot with Support and Pressure frozen; this tutorial adds one separate practice source so arrow navigation has several segments.

1. Select `practice-study` in `Local project`, then select `Workspace`. — "Work from the source to the passage, then inspect its coding and provenance."
2. Select `Import source`; enter `keyboard-practice` in `Source name` and choose `Plain text` in `File format`. — "A short practice source makes keyboard navigation easy to see."
3. Paste the following into `Or paste source text`; select `Import into project`. — "Blank lines separate the three practice passages."

   ```text
   My sister gives me support when work feels stressful.

   I feel pressure at work and take a short walk afterward.

   Support from friends helps me manage pressure.
   ```

4. Select `keyboard-practice` under `Sources`; enter `researcher` in `Human actor`. — "Coding decisions record who made them."
5. Choose the intended version in `Frozen codebook`. — "The selected frozen version supplies the available codes."
6. Click the first segment and inspect `Whole segment selected`. — "With no selected text, coding applies to the whole segment."
7. [zoom] Inspect the number beside `Support`, then press that displayed number outside any field. — "Keys 1 through 9 apply the corresponding displayed code."
8. Wait for saving to finish; inspect `Current assignments`. — "The assignment shows the coded excerpt and its span."
9. Press the down arrow to move to the second segment. — "Arrow keys move between segments in the current source."
10. Press the number displayed beside `Pressure`; wait for saving to finish. — "Wait until the code buttons are enabled before the next shortcut."
11. Press the up arrow to return to the first segment. — "Navigation keeps the selected passage and coding panel together."
12. Select only `My sister gives me support` in the first segment. — "Select text when the code should cover only part of the passage."
13. [zoom] Inspect `Selected span` and its quoted text, then click `Support`. — "Span offsets are relative to the segment and count Unicode code points."
14. Wait for saving, then inspect the whole-segment and selected-span entries in `Current assignments`. — "Several coded spans can belong to the same segment."
15. Select `Remove assignment` on the whole-segment Support entry. — "Removal changes current coding while retaining the original decision."
16. Expand the assign and remove entries under `Provenance`. — "The audit trail retains both the assignment and its removal."
17. Select text again, then press Escape and inspect `Whole segment selected`. — "Escape clears the current span selection."
18. Select the same words again, then choose `Use whole segment`. — "The visible button also clears a selected span."
19. Move to the third segment and apply `Support`, wait, then apply `Pressure` using their numbers. — "Multiple codes can apply to the same passage."
20. Select `a short walk` in the second segment; expand `New code from this passage`. — "You can name a new idea without leaving the transcript."
21. Enter `a short walk` in `Code name` and `Walking as a response to pressure.` in `Definition (optional)`. — "A code can use the participant's own words."
22. Leave `Keep the selected text as a positive example` checked. — "The selected words can become a positive example for the new code."
23. Select `Create, freeze and assign`; wait for saving to finish. — "This creates the code, freezes a version and assigns it to the selected passage."
24. Inspect `Frozen codebook`, `Current assignments` and the new entry under `Provenance`. — "The new frozen version includes all current draft edits."
