# Build and freeze your codebook

Guide sections: 6 (manual codebook editing; proposals are in tutorial 09)
Target length: 3 min
Starting state: practice-study after imported

1. Select `practice-study` in `Local project`, then select `Codebook`. — "Your codebook belongs to you."
2. Under `Create code`, enter `Support` in `Name`. — "Give the idea you want to track a clear name."
3. Enter `Practical or emotional help from other people.` in `Definition`. — "A definition explains what the code means."
4. Leave `Parent code` at `No parent`. — "Parent codes organize related definitions into a hierarchy."
5. Enter `Practical help or emotional support from other people.` in `Include`. — "Inclusion guidance explains when the code should apply."
6. Enter `Demands or stress without help from others.` in `Exclude`. — "Exclusion guidance helps distinguish neighboring codes."
7. Enter `My sister gives me support when work feels stressful.` in `Positive examples, one per line`. — "Use examples to make the definition easier to apply consistently."
8. Enter `I feel pressure at work and take a short walk afterward.` in `Negative examples, one per line`. — "Negative examples clarify what lies outside the code."
9. Keep `Status` at `Active`; select `Save draft code`. — "Saving creates a draft that you can still edit."
10. Under `Create code`, enter `Pressure` in `Name` and `Experienced demands or stress.` in `Definition`. — "Add the other codes your study needs."
11. Keep `Status` at `Active`; select `Save draft code`. — "An active draft code is needed before you can freeze a usable version."
12. Review both code cards, then select `Freeze codebook`. — "Freezing captures an immutable version of the draft codebook."
13. [zoom] Expand the new entry under `Frozen versions`. — "The saved version keeps the definitions used for coding."
14. Select `Workspace` and inspect `Frozen codebook`. — "Choose the intended frozen version before assigning a code."
15. Return to `Codebook`; select `Edit Support`. — "Later edits change the draft rather than an existing frozen version."
16. Change `Definition` to `Practical or emotional help from family, friends or other people.` — "Refine the wording when your understanding develops."
17. Select `Save draft code`, then `Freeze codebook`. — "Freeze again when the revised definitions are ready for use."
18. Inspect both entries under `Frozen versions`, then inspect `Frozen codebook` in `Workspace`. — "Existing decisions retain their original version and historical code name."
