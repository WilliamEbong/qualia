# Organize cases and attributes

Guide sections: 5
Target length: 2–3 min
Starting state: practice-study after imported

1. Select `practice-study` in `Local project`, then `Workspace`. — "A case represents the unit you want to compare."
2. Inspect `Cases`, then select `Edit` beside `p01`. — "The practice CSV has already created three participant cases."
3. Inspect `Case name` and keep `p01`. — "Choose case names that fit your research design."
4. [zoom] Inspect the checked, disabled source under `Add linked sources`. — "Existing source links remain attached and cannot be removed in this form."
5. Inspect `Attributes, one name=value per line` for `group=north`, `age=24` and `wellbeing=4`. — "Analysis uses case attributes rather than source attributes."
6. Change the age line to `age=`; keep the other lines and select `Save case`. — "An empty value marks an attribute as missing without deleting its name."
7. Select `Edit` beside `p01` and inspect the empty age value. — "Missing values are not silently converted to zero."
8. Restore `age=24` in `Attributes, one name=value per line`; select `Save case`. — "Submitted values update the named attributes."
9. Set `Filter by case` to `p01` and inspect `Sources`. — "The case filter shows sources linked to the selected case."
10. Set `Filter by case` to `All cases`, then select `Create case`. — "A source may link to more than one case."
11. Enter `Practice comparison` in `Case name`. — "Choose the unit of comparison deliberately."
12. Under `Add linked sources`, select the sources containing the sister and friends responses. — "Each linked case receives the selected segments from its sources."
13. Enter `region=north` in `Attributes, one name=value per line`; select `Save case`. — "Enter one attribute name and value on each line."
14. Set `Filter by case` to `Practice comparison` and inspect the two linked sources. — "Multiple source links do not automatically separate speakers inside a transcript."
15. Select `Edit` beside `Practice comparison` and inspect `Add linked sources` again. — "Shared sources can contribute to several groups, so totals may overlap."
16. Select `Close`, then return `Filter by case` to `All cases`. — "Numeric analysis counts eligible cases, not individual segments."
