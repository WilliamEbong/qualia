# Explore the matrix and Analysis workbench

Guide sections: 9–10
Target length: 4 min
Starting state: practice-study after coded

Recording note: Use the unchanged section 3 snapshot: three linked cases, with Support and Pressure each assigned to two segments.

1. Select `practice-study` in `Local project`, then select `Matrix`. — "Each cell counts distinct currently coded segments for one code and case."
2. Inspect the `Support` row under `p01`, `p02` and `p03`. — "Repeated spans of one code on a segment count once in a matrix cell."
3. Select the cell at `Support` and `p03`. — "A matrix cell leads back to its supporting coded excerpts."
4. In `Retrieval`, inspect `Code`, `Case` and the excerpt, then select `Open in transcript`. — "Use the passage context to interpret the count."
5. Select `Analysis`; inspect `Code frequencies` and the selected segment and case totals. — "Analysis describes current manual and accepted coding."
6. [zoom] Inspect the denominators and the `Segment %` and `Case %` columns. — "Each code appears on two of the three practice segments and cases."
7. Select the `Support` chart bar and inspect `Source evidence`. — "Chart bars and counts open the evidence contributing to the result."
8. Expand `Coding evidence` with its displayed current-event count. — "Coding evidence keeps event identities, actors, spans and frozen versions."
9. Under `Analysis criteria`, keep `Analysis source` at `All sources` and `Analysis case` at `All cases`. — "Source and case filters narrow the selected evidence."
10. Enter `support` in `Literal text query`; expand `Code filter` with its available count and select `Support`. — "The text query is a case-insensitive substring search."
11. Set `Match selected codes` to `Any selected code`; select `Apply analysis criteria`. — "All filter types intersect when the report is calculated."
12. Read `Applied criteria`, then clear `Literal text query` and uncheck `Support` in `Code filter`. — "No code selection imposes no code filter."
13. Set `Group by case attribute` to `group`; select `age` and `wellbeing` under `Explicit numeric case attributes`. — "Choose numeric measurements explicitly rather than treating identifiers as numbers."
14. Set `Co-occurrence unit` to `Present in the same segment`. — "Segment co-occurrence counts passages carrying both codes anywhere."
15. Expand `Word-frequency options`; set `Minimum word length` to `3` and `Top words` to `10`. — "Word-frequency options control the descriptive word list."
16. Enter `the, and` in `Explicit stopwords`; select `Apply analysis criteria`. — "Stopwords are explicit, with no hidden stemming or synonym groups."
17. Expand the north and south entries under `Case-group comparisons`. — "Group percentages use each group's own segment and case denominators."
18. Inspect `Code co-occurrence`; select the Support and Pressure cell. — "Selecting a code pair opens its contributing passages."
19. Expand `Exact pair counts and segment-presence Jaccard`. — "Jaccard measures segments carrying both codes divided by those carrying either."
20. Set `Co-occurrence unit` to `Positive-length span overlap`; select `Apply analysis criteria`. — "Overlap requires coded spans to share more than a touching boundary."
21. Inspect `Code co-occurrence` and `Exact pair counts and segment-presence Jaccard` again. — "Jaccard still uses segment presence even when the count uses span overlap."
22. Inspect `Words in selected text`, comparing `Occurrences` with `Distinct segments`. — "Repeated words and the number of passages containing them are different counts."
23. Inspect `Numeric case attributes`: `Valid`, `Missing` and `Invalid / conflicting`. — "Check data quality before interpreting numeric summaries."
24. Read `Mean`, `Median` and `Sample SD` for `age` and `wellbeing`. — "Each eligible case contributes one numeric observation."
25. Choose `age × wellbeing` in `Scatter fields` and inspect `Paired cases` and `Pearson r`. — "The constructed practice pairs give a correlation of one, not a causal finding."
26. Expand `Exact paired case values`; select a case row to inspect its evidence. — "Trace a numeric point back to the selected source material."
27. Select `Download frequency SVG` and `Download scatter SVG`. — "Standalone charts include labels and criteria that may contain research metadata."
28. Expand `Analysis methods and provenance`. — "The report records its input identity and contributing coding evidence."
29. Select `Refresh analysis` and inspect the refreshed `Applied criteria`. — "Refresh reloads evidence and preserves applied criteria, not unsaved form changes."
