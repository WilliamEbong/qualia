# Install and open Qualia

Guide sections: 2 (Windows installer and everyday launch only)
Target length: 2–3 min
Starting state: empty workspace

1. [card] Show `Download Qualia-<version>.zip from https://github.com/WilliamEbong/qualia/releases`. — "Download the latest release zip for Windows."
2. [card] Show `Right-click the zip → Properties → Unblock → OK`. — "Unblock the downloaded zip before extracting it."
3. [card] Show `Extract the zip to a permanent application folder, such as Documents\Qualia`. — "Keep the application in a folder you will retain."
4. [card] Show `Open the extracted folder and double-click Install Qualia`. — "The installer explains each step as it runs."
5. [card] Show `First run: internet required; allow a few minutes`. — "The installer adds the tools Qualia needs and the AnnoMI demonstration project."
6. [card] Show `Qualia shortcuts appear on the Desktop and in the Start menu`. — "Qualia opens automatically when installation finishes."
7. In the opened app, hold on `Project catalogue` and the installed demonstration project. — "The demonstration lets you explore public research material locally."
8. Select the installed demonstration project in `Local project`, then select `Workspace`. — "Use Qualia's own window for your research."
9. Select `Home` and hold on `Project catalogue`. — "Manual coding does not require an AI account."
10. [card] Show `Close the Qualia window; allow about three minutes for shutdown`. — "Closing the window lets Qualia shut itself down."
11. [card] Show `Double-click the Qualia icon`. — "The same icon opens your local workspace again."
12. In the reopened app, inspect `Local project` and select the demonstration project. — "Each local project keeps its material, codebook and history together."
13. [card] Show `Research location: %USERPROFILE%\Qualia\projects and %USERPROFILE%\Qualia\vault`. — "Research workspaces are stored separately from the application folder."
14. [card] Show `Update: extract the newer release and run Install Qualia again`. — "Updating keeps your separately stored research projects."
